# 雅思教练每日检查清单

## 目的

每天快速确认这个产品是否仍然处于“可稳定自用”的状态。

## 每日检查项

### 1. 日期与每日状态

- 右上角日期是否显示为今天
- 每日任务是否已经按今天重置
- 首页的阶段、今日进度、教练提醒是否正常显示

### 2. 模块可用性

- 语法模块能否正常打开，并显示当天题目
- 发音实验室能否正常打开，并显示当天阶段
- 听力专项是否仍为 `3` 题结构
- 词汇模块是否仍为 `6` 个新词 + `4` 个复习词节奏
- 阅读模块是否仍为 `1` 篇 + `3` 题
- 写作模块是否显示正确题型与今日重点
- 口语模块是否显示当天口语题目

### 3. 训练层一致性

- 首页任务标题是否和实际模块内容一致
- 目标追踪中的核心指标是否正常显示
- 周复盘和月度诊断是否可以打开

### 4. 同步

- 设置页能否打开
- 云同步提示区是否可正常显示状态
- 上传按钮和下载按钮是否可点击

## 建议记录方式

每天只记三件事：

- 今天是否有任何模块打不开
- 今天是否有内容明显重复或错位
- 今天同步和日期是否正常

## 发现问题时优先级

### 高优先

- 页面打不开
- 同步失败并导致状态异常
- 日期错乱导致每日任务不更新

### 中优先

- 题目重复明显
- 页面内容和首页描述不一致
- 周复盘或月度诊断打不开

### 低优先

- 某条文案不够自然
- 个别例句不够理想
- 个别反馈还不够像正式评估
